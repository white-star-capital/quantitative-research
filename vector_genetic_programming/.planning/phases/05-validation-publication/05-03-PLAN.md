2. **What is VGP** (1-2 paragraphs): Genetic programming framework that evolves trading strategies from multi-asset crypto OHLCV data using DEAP + vectorbt. Walk-forward validation with DSR reporting confirms out-of-sample performance.


| Module | Purpose |

| `vgp/data` | DataLoader, FeatureEngine ([T×F×A] float32), WalkForwardSplitter |

| `vgp/backtest` | EvalConfig, evaluate() — fitness tuple with baked-in transaction costs |
| `vgp/analysis` | WalkForwardRunner, compute_dsr(), plot_pareto_front/equity_curves/tree_graph |
