| Boundary | Description |
|----------|-------------|
| developer workstation → pip | Third-party packages fetched from PyPI; pinned versions reduce supply-chain risk |
| pyproject.toml → installed environment | Incorrect pins could silently install incompatible versions; this is the primary risk in Phase 1 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | pyproject.toml version pins | mitigate | Exact pins (deap==1.4.4, vectorbt==1.0.0) prevent silent upgrades; numpy<2.3 upper bound blocks numba breakage |
| T-01-02 | Denial of Service | numpy/numba incompatibility | mitigate | numpy>=2.0.0,<2.3 pin enforced in pyproject.toml; smoke test in Plan 02 asserts this at runtime |
| T-01-03 | Information Disclosure | LICENSE absence | mitigate | MIT LICENSE created in this plan; COMM-02 satisfied |
| T-01-04 | Spoofing | Incorrect Python version in environment | mitigate | .python-version pins 3.12; pyproject.toml requires-python = ">=3.12" provides double enforcement |
